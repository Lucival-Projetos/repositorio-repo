# Este projeto tem como objetivo oferecer um aplicativo para o aprendizado de idiomas.

### Com o intuito de ajudar na formação de profissionais para o mercado internacional, traremos mais atualizações futuramente.

### Temos a intenção de adicionar línguas mais complexas futuramente, como japonês, mandarim, francês, russo, entre outras...

> Cadastro temporário
> Cadastro com e-mail
> Cadastro somente com nome de usuário
